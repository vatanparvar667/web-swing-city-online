# Web Swing 3D — ночной город

Браузерная игра в духе Spider-Man: раскачка на паутине по ночному Нью-Йорку, бой с бандами, гонки по кольцам и мультиплеер. Один HTML-файл, без сборки и без своего сервера.

**Играть:** https://vatanparvar667.github.io/web-swing-city-online/

## Мультиплеер

Все, кто открыл ссылку, оказываются в одном городе и видят друг друга: позу, костюм, нить, ник над головой. Перед стартом нужно ввести имя.

- Кнопка «Своя комната» создаёт приватную ссылку вида `?room=abc123` — по ней попадут только те, кому вы её дали.
- Связь идёт через публичный MQTT-брокер `public.cloud.shiftr.io` (порт 443). Ники и координаты передаются открыто, поэтому не пишите в ник и чат ничего личного.
- Если брокер недоступен, игра работает в одиночном режиме.

## Управление

| Клавиша | Действие |
|---|---|
| Shift / F (держать) | раскачка: нить сама цепляется и отпускается; на земле — паркур, в стену — забег вверх |
| W A S D | бег и руление |
| Пробел | прыжок; на нити — рывок; в воздухе — сальто; при паучьем чутье — уклонение |
| ЛКМ / J | удар, серия из трёх; издалека — веб-удар с рывком |
| V / колесо / ПКМ по бандиту | выстрел паутиной: руки, ноги, кокон |
| E / ПКМ | рывок к точке под прицелом |
| C | пикирование |
| G | взять / бросить предмет |
| T | костюм; пятый — Железный человек: Пробел вверх, C вниз, Shift форсаж, V репульсор |
| Y | позвать босса |
| X | дрон: камера за ним; WASD — полёт, Пробел/C — вверх/вниз, Shift — форсаж, ЛКМ (держать) — огонь, ПКМ/E — таран, X — вернуть |
| Enter | чат |
| N / B / K / M | +3 часа / дождь / музыка / звук |
| Esc / P | пауза |

На телефоне — джойстик и кнопки на экране.

## Дрон

X (на телефоне — кнопка «Дрон») запускает дрон: камера переходит к нему, герой ждёт на месте. Батарея — 90 секунд, после возврата или взрыва — 4 секунды перезарядки. Очередь из двух стволов бьёт бандитов, босса, пузыри и машины (машина взрывается после 5 попаданий). Таран или удар на скорости — взрыв: бандиты в радиусе выбывают, машины взрываются цепочкой, прохожих раскидывает, боссу −30…45. В мультиплеере чужие дроны, их выстрелы и взрывы видны.

## Босс

Гигантский Губка Боб выходит из залива через минуту после старта, потом раз в 4 минуты (или по клавише Y). Бродит по воде вдоль берегов, топает (ударная волна бьёт тех, кто низко), пускает пузыри и бьёт рукой вблизи. Паутина и репульсор, удары, брошенные машины и прыжок на голову снимают здоровье; 4 попадания паутиной опутывают его. В мультиплеере босс общий для всей комнаты.
