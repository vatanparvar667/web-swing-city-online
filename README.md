# Web Swing 3D — ночной город

Браузерная игра в духе Spider-Man: раскачка на паутине по ночному Нью-Йорку, бой с бандами, гонки по кольцам, боссы, техника и мультиплеер. Один HTML-файл, без сборки и без своего сервера.

**Играть:** https://vatanparvar667.github.io/web-swing-city-online/

## Мультиплеер

Все, кто открыл ссылку, оказываются в одном городе и видят друг друга: позу, костюм, нить, ник над головой. Перед стартом нужно ввести имя.

- Кнопка «Своя комната» создаёт приватную ссылку вида `?room=abc123` — по ней попадут только те, кому вы её дали.
- Связь идёт через публичный MQTT-брокер `public.cloud.shiftr.io` (порт 443). Ники и координаты передаются открыто, поэтому не пишите в ник и чат ничего личного.
- Если брокер недоступен, игра работает в одиночном режиме.

## Управление

| Клавиша | Действие |
|---|---|
| Shift / F (держать) | раскачка: нить сама цепляется и отпускается; на земле — паркур, в стену — забег вверх |
| W A S D | бег и руление |
| Пробел | прыжок; на нити — рывок; в воздухе — сальто; при паучьем чутье — уклонение |
| ЛКМ / J | удар, серия из трёх; издалека — веб-удар с рывком |
| V / колесо / ПКМ по бандиту | выстрел паутиной: руки, ноги, кокон |
| E / ПКМ | рывок к точке под прицелом |
| C | пикирование |
| G | взять / бросить предмет |
| T | костюм; пятый — Железный человек: Пробел вверх, C вниз, Shift форсаж, V репульсор |
| Y | позвать боссов: сначала Губку Боба с Патриком, потом Кинг-Конга |
| 1–5 | техника: 1 — дрон, 2 — боевой робот, 3 — вертолёт, 4 — ракета верхом, 5 — танк; та же цифра или X — выйти |
| X | дрон (без техники): камера за ним; WASD — полёт, Пробел/C — вверх/вниз, Shift — форсаж, ЛКМ (держать) — огонь, ПКМ/E — таран, X — вернуть |
| Enter | чат |
| N / B / K / M | +3 часа / дождь / музыка / звук |
| Esc / P | пауза |

## Телефон

Играть удобнее горизонтально. Слева джойстик, свайп по экрану — обзор, справа кнопки: «Паутина» (держать — раскачка; у Железного человека и дрона — форсаж), «Прыжок» (у Железного человека и дрона — вверх), «Нырок» (вниз), «Рывок» (у дрона — таран), «Удар» (у дрона — огонь), «Сеть», «Взять / бросить», «Техника» (меню: дрон, робот, вертолёт, ракета, танк, выйти); в технике подписи кнопок меняются под неё. Сверху — чат и пауза. На Android игра при старте разворачивается на весь экран. На телефоне меньше прохожих и машин, а разрешение подстраивается под скорость.

## Дрон

X или 1 (на телефоне — «Техника» → «Дрон») запускает дрон: камера переходит к нему, герой ждёт на месте. Батарея — 90 секунд, после возврата или взрыва — 4 секунды перезарядки. Очередь из двух стволов бьёт бандитов, босса, пузыри и машины (машина взрывается после 5 попаданий). Таран или удар на скорости — взрыв: бандиты в радиусе выбывают, машины взрываются цепочкой, прохожих раскидывает, боссу −30…45, чужой технике — урон. В мультиплеере чужие дроны, их выстрелы и взрывы видны.

## Техника

Цифры 1–5 (на телефоне — кнопка «Техника»). Пока ты в технике, удары по герою снимают её броню; броня кончилась — взрыв, героя подбрасывает, а технику можно взять снова через 20 секунд.

- **Боевой робот** (~14 м): WASD — шаг, Shift — бег, Пробел — прыжок на ускорителях (в воздухе держать — тяга, приземление с высоты бьёт по площади), ЛКМ — пушки, ПКМ — залп из 4 ракет, E — удар кулаком (машины улетают). Давит машины и бандитов, ходит вброд по заливу — можно подраться с Губкой Бобом в воде.
- **Полицейский вертолёт**: WASD — полёт, Пробел/C — вверх/вниз, Shift — форсаж, ЛКМ — пулемёт, ПКМ — пара ракет; прожектор светит в точку прицела. Друг может встать на полозья — вертолёт повезёт его.
- **Ракета верхом**: летит туда, куда смотрит камера, A/D и W/S — подруливание, Shift — турбо, топлива на 14 секунд. Любое касание — большой взрыв, героя подбрасывает вверх, можно сразу цепляться паутиной. E — соскочить, ракета летит дальше сама.
- **Танк**: W/S — ход, A/D — поворот корпуса, башня и ствол следуют за прицелом, ЛКМ — пушка (раз в 1.6 с), ПКМ — пулемёт, Shift — полный ход. Давит машины; в воде тонет.

В мультиплеере чужая техника, её выстрелы и взрывы видны всем; снаряды друзей бьют по твоей технике — можно устроить бой роботов или танков. Героя без техники взрывы только отбрасывают.

## Боссы

- **Губка Боб и Патрик** выходят из залива вдвоём через минуту после старта, потом раз в 4 минуты (или по Y). Губка Боб топает (волна бьёт тех, кто низко), пускает пузыри и бьёт рукой. Патрик держится рядом, таранит с разбега, прыгает пузом (волна до 60 м) и даёт оплеухи; если цель рядом с обоими — комбо: прыгают вместе.
- **Кинг-Конг** забирается на самую высокую башню (оранжевый столб) через 3 с лишним минуты после старта, потом раз в 5 минут (или по Y, когда дуэт уже в городе). Бьёт себя в грудь — волна во все стороны сбивает героев в воздухе и вертолёты, бросает глыбы по тем, кто далеко, отшвыривает тех, кто подлетел вплотную. Чтобы драться, раскачивайтесь вокруг башни или прилетайте на вертолёте; повержен — падает с башни.

Паутина и репульсор, удары, брошенные машины, прыжок на голову и оружие техники снимают здоровье; 4 попадания паутиной опутывают босса. В мультиплеере боссы общие для всей комнаты.
